version: 0.57.0
title: Working on and Chat for sit inside the message box
pages: [picking-the-client, home]
---

On Home, **Working on** and **Chat for** now sit inside the message box, just above **Send**.

Set **Working on** to a project, and **Chat for** starts on that project's client. Pick a different client if the chat is about someone else.

The "Enter to send" hint no longer shows under the box. Enter still sends, and Shift and Enter still starts a new line.
