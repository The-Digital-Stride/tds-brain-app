Cortex knows who you are by a sign-in. Usually you don't see it. If you do, the page says "Sign in to TDS Brain". Here is what to do.

## Signing in

1. Press Command and Space. This opens Spotlight, the Mac search box.
2. Type TDS Brain Sign-in and press Return.
3. Chrome opens with your sign-in.
4. Leave the sign-in page open. It checks every few seconds, and opens Cortex once you are signed in.

## If Chrome opens the wrong profile

Chrome can hold more than one profile, such as a work one and a personal one. If the wrong one opens:

1. Close that Chrome window.
2. Switch to the Chrome profile you use for work.
3. Open TDS Brain Sign-in again.

## If it still won't work

See [Fixing problems](help:fixing-problems). If that doesn't help, ask an owner or a scout.

## Good to know

The sign-in helper keeps the name TDS Brain Sign-in for now, even though the app is called Cortex.
