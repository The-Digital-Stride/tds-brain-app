title: Archive a finished project
pages: [projects]
---

Press **Archive** when a project is finished. Cortex asks what should happen to each open to-do.

Archived projects leave the list but stay safe. Find them under the **Archived** status filter, and press **Unarchive** to bring one back.

To remove an archived project for good, press **Delete** and type its name. Only the project's Account Owner or the Brain's owner can do this.
