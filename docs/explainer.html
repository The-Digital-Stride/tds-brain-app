TDS Brain App: a friendly face for the brain

The brain is our shared folder of know-how. The app is one more way to use it, next to the terminal and the code editor. The app keeps none of the brain inside it, and the brain knows nothing about the app. Use the app, or carry on in the terminal. Both talk to the same helper, Claude, about the same folder.

Each picture plays once when you scroll to it. Press Play again to watch it again. If nothing moves for you, that is fine, because every picture also shows its finished state.

1. Where the app sits

Think of a restaurant. The app is the new menu and waiter. The kitchen (Claude and the brain) was already there and works just the same.

2. What the app looks like

A sketch, not the real thing. Watch a chat unfold: you ask, Claude asks back, you give permission, and a to-do gets ticked.

Menu and search

Where you go: new chat, skills, to-dos, documents, settings. You only see the parts your role may use. "Search or jump to" (or Cmd+K) finds to-dos, chats, skills, documents and pictures.

Changes the brain: no

Chats

Several chats can be open at once. Earlier chats wait in a drawer. Star the ones you love, filter work and personal, and delete old ones.

Changes the brain: no

Chat with a client

Pick a client and a skill, add files, and answer Claude's questions with buttons. Files and pages Claude makes are listed beside the chat and in Documents.

Changes the brain: only what you allow

To-dos (the Workbench)

Add, edit, pass to a teammate, set a due date, tick off. Every change goes through the brain's own to-do tool, never straight from the app.

Changes the brain: yes, through its own tool

Pinned and often used

Pin the skills you use most. The app also shows the ones you use often, from the usage log the brain already keeps.

Changes the brain: no

Levels and helpers

The app picks a lighter or heavier setting to suit the job, like a pocket calculator for sums and a computer for a spreadsheet. Big jobs can be split between helpers.

Changes the brain: no

Pages

Ask for something to look at and the app shows it in a viewer. See the next section.

Changes the brain: no, unless you file one

3. Pages: ask for something to look at

A page is anything visual Claude makes for you: a chart, a one-pager, a checklist. It is one web page saved as a single file. Press a step to jump to it, or press Play again.

Added recently New

These fixes make pages more dependable. You use pages the same way as before.

Links open in a new tab

Clicking a link inside a page opens the website in a new browser tab.

Pages made by scripts still show

Sometimes Claude saves a page by running a small program instead of the usual way. The app spots those pages too.

Borrowed code kept fresh

Pages often borrow ready-made code, like borrowing a cookbook. The app keeps a copy. A copy that doesn't say how old it is gets renewed after a week. If the internet is down, the old copy still works.

An honest "works offline" label

A page that fetches extra code when you open it says it needs the internet. The "works offline" label only appears when it is true.

Leftover files swept away

If the app stops half-way through saving, a scrap of file can be left behind. When the app starts, it clears away old scraps.

More automatic checks

New tests follow the whole journey, from asking to downloading, the way you do. One check that sometimes failed for no reason is fixed.

One idea, not decided yet: pointing at part of a page and saying "change this".

4. What happens when the brain is updated

Nobody installs anything. The app notices the folder changed and reads it again.

5. The steps that need care

Permission cards

The app should ask in plain words before Claude saves a file or does something risky, with Allow and Don't allow buttons, rather than switching the safety checks off.

Only this laptop may talk to it

The app can start Claude with access to files, so no other web page may reach it. This needs a security check before the whole team uses it.

Changes reach everyone

Ticking a to-do edits a shared file, and the team gets it in about 90 seconds. The app never writes brain files itself. It uses the brain's own tools, which follow the brain's rules.

Pages are kept in a sealed box

A page can run its own code, so the viewer locks it in a sandbox. It can show things but cannot touch your files or the app.

Anthropic's rules

Nobody signs in again, because the app uses the Claude Code sign-in each person already has. The open question is permission: Anthropic's rules for apps built on Claude Code are unclear for staff tools, so we want their answer before rollout.

Words used here

The brain
Our shared folder of skills, house rules and client notes. It sits on each laptop and is kept in step by the sync app.
Claude Code (the helper)
The program that reads the brain and does the work, whichever way you asked: app, terminal or editor.
Sandbox
A sealed box for running something you did not write yourself. Like a fish tank, you can watch, but nothing gets out.
Version
One saved try of a page. Like numbered pages in a notebook, you can flip back to an earlier one.
Self-contained
One file with everything inside, so it works when you send it to someone or open it with no internet.
This page is one file with nothing loaded from the internet. It works in the app, in a browser and from a folder. It does not save anything on your computer.
