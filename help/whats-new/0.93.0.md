Every project now has a **Chats** tab. It lists each chat you had for that project, newest first.

Press a chat's name and it opens beside the project, so you carry on where you left it. Each row says whether you have saved the chat to the project. Press **Save to project** to share a summary with the team.

Only you can see the list. Your chats stay on this Mac, as before.
