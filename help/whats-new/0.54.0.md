---
version: 0.54.0
title: Settings now has tabs
pages: [settings, health]
---

**Settings** is now split into five tabs: **General**, **Claude**, **Skill levels**, **Health** and **About**. They look like the tabs in the Ads tools. Each tab is one short page, so you scroll less.

Settings opens on the tab you used last. A red dot on **Health** shows when something is wrong, wherever you are in Settings. **⌘K** search has an entry for each tab, such as "Settings: Claude". Help opens the page for the tab you are on.

The names of the sections inside each tab have not changed.
