Plan for the TDS Brain app · 23 November 2026

Projects Release 2

Release 1 gave every project its own folder. Release 2 makes the rest of the app use it. First, chats learn which project they are for. After that come update logs, activity, meetings, emails and a weekly round-up.

The problem

Today a chat forgets the project

Phase 1 · done

The chat knows its project, and Claude saves there

Step 1 · where it comes from

The project is picked up from one of three places:

  • Working on on the Home screen.
  • A to-do that sits in a project.
  • The new New chat for this project button on the project page.
Step 2 · the app checks

The app looks the project up itself. If it is unknown, archived (put away) or belongs to another client, the chat will not start. Then the app remembers the project for that chat, even when you reopen it from History.

Step 3 · Claude is told

Claude is told the project's folder and to save what it makes there, without asking. It also tells you where each file went.

What still goes somewhere else

Private details

Names, emails and phone numbers stay on this Mac and are never linked to a shared project.

Call notes

Saved by the meeting-notes skill, then linked to the project.

To-dos

Saved by the to-do skill, with the project filled in.

Data pulls and ad-platform files

Saved where the brain's rules say, then linked to the project.

A client chat with no project? If you name a project, Claude uses it. If the client has open projects and you don't, Claude asks which one the work is for. If the client has none, nothing changes. To switch project, start a new chat.

The road ahead

Five more steps, one at a time

donePhase 1

Chats know their project

Files made in a project chat land in the project.

donePhase 2

Updates log

A running diary for each project. One small file per entry, so two people never clash. Each is marked team-only or fine for the client.

donePhase 3

Since you last looked

Open a project and see what changed since your last visit, plus what is coming up. Your last visit is kept on your own Mac.

building nowPhase 4

Your meetings

Your last and next meeting show on the project page, for you only. Filing the notes then shares them.

nextPhase 5

Email entries

Claude drafts a short summary of an email thread. It is saved only after the inbox's owner has read it and said yes.

nextPhase 6

Weekly round-up

On Mondays the Account Owner can get a short "where we are" for each project. It reads shared files only, and nothing is saved until they click.

Taking care

Where the risky steps are

The app picks the folder

The chat only sends a project name. The app finds the folder itself, so a made-up request can't point Claude at the wrong place.

Private data never gets shared

Anything with names, emails or phone numbers stays out of project folders. Nothing from private areas is linked to a shared project.

Reopening an old chat must never break

If the saved project is missing or something fails, the chat still opens, just as it does today.

Claude asks rather than guesses

A wrong guess would quietly file a document in the wrong project. So Claude asks which project when it isn't sure.

Nothing is shared by surprise

Emails and round-ups are saved only after a person has seen them and said yes.

Brain rule changes are prepared as files first and copied into the brain only when Ian says yes.
