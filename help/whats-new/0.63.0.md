title: Undo after you delete, and buttons that work the same everywhere
pages: [deleting-a-chat, favourites, ad-manager]

Deleting an earlier chat no longer asks first. The row shows **Undo** for 10 seconds instead. To-dos and files use the same Undo line.

To start a new chat, press the plus button at the end of the **Open** and **Earlier** row.

Buttons now look and work the same across Cortex. Stars are called favourites everywhere. A favourite to-do on Home opens the to-do itself, not a chat. Ads panels ask **Discard your changes?** before you leave typed work.
