A project code now works from anywhere in an email thread. Paste it once, and later replies still find the project. Signatures never count.

Press **Write an email** on a project's Overview. Gmail opens in a new tab with the code already in it.

When several people are on one thread, the project's Updates tab shows it as one row. Each person adds only what is new, and older parts sit under **Earlier in this thread**.
