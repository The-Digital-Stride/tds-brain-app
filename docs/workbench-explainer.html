Cortex Workbench

Cortex is getting a new menu item called Workbench. It holds tools. The first tool is the Ad Manager, the same Ads tab the brain's Workbench page has today, rebuilt inside Cortex.

1. How you get to a tool

Workbench works like Help. Click it on the left and a drawer slides out with a list of tools, each with an icon and a name. Click a tool and it fills the big main area, and the drawer tucks itself away.

2. What happens when you press a button

Cortex never changes brain files by itself. When you press Approve or Apply now, Cortex asks a small helper skill called tdsapp-ads. The helper asks the brain's own ads code, the same code the Workbench page uses. So both always follow the same rules, and Cortex works even when the Workbench page isn't running.

3. Apply now can never happen twice by accident

Apply now changes a real ad account, so it gets extra care. Cortex writes down that an apply has started before it begins, and never stops one halfway. If it takes too long, or Cortex restarts, it says it doesn't know the result and keeps the button off until you've checked the account.

What stays the same, and what's different

The same as the Ads tab

  • The Account picker, with "(3 waiting)" beside accounts that need you.
  • Proposals waiting for a decision, and recent decisions.
  • Approve, Request changes, Reject, Dry run, Apply now, client emails and Sign off the report.
  • The board: data health, the 16 Run cards, the daily standup and the deep-dive tables.
  • Who may decide: the client's reviewer, its owner or an owner.

Different, to fit Cortex

  • Run starts a Cortex chat instead of a Terminal window.
  • A proposal's details open in the right-hand panel.
  • "Are you sure?" questions appear in the page, not as pop-ups.
  • Reports and PDFs open in Cortex's file viewer.
  • Recent decisions says "last 14 days", which is what it really shows.
  • Home gets an "Ads approvals" card.

How it gets to the team

  1. Build it in a separate copy of Cortex, with checks and reviews.
  2. Ian says yes to copying the tdsapp-ads helper into the brain. Until then nobody sees anything new.
  3. Ian and Pete try it: a dry run on a real account, then one harmless Apply now they pick.
  4. Only owners and scouts see it at first. Pete releases the helper to everyone when he's happy.

Only Macs that can reach Google Ads see the Ad Manager, just like the Ads tab today. The Workbench page keeps working the whole time.
