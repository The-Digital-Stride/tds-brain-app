**Write an email** on a project's Overview now opens Gmail in a small window beside the project, not in a new tab.

If the client's files in the brain list contacts with an email address, an **Email to** list shows next to the button. Pick a name and Gmail opens with that person filled in. The main contact is picked to start with.

Choose **Someone else** to fill in the address yourself.
