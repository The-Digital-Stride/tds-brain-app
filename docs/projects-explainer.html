Projects in Cortex

A project is one tidy place for a piece of work. Its to-dos, files, pictures and documents (and later its chats, notes and time) all point at it, so you can find everything about it in one go.

The shape

Client, then project, then to-do

  • One-off projects have an end, like a website rebuild. Ongoing ones are retainers, like monthly Google Ads work.
  • Each project is a folder, for example clients/skyseal/projects/website-rebuild/, with a short card file called project.md.
  • The card holds the same details Monday does: Account Owner, team, service, dates, budget hours, a health light and a client-comms light.
  • A project's folder name never changes, even if you rename its title. That's why links to it never break.

The tidy-up

Sorting out the old labels, with your say-so

Sixty of today's to-dos have a project: label typed in by hand, and some of them don't match anything. The Projects app suggests a fix for each label. Nothing changes until you approve that row.

The tidy-up can fix a teammate's to-do too, but it only ever changes the client, project and stage lines. Old folders in projects/ show up as The Digital Stride's projects straight away, without being moved.

When

What arrives when

Release 1

Projects app and project page, the Client → Project picker, to-dos with project and stage, images and documents, search, the tidy-up.

Release 2

Chats and call notes carry the project. Pages are saved in the project. Updates log. Claude asks "which project?".

Release 3

Ads work tagged to a project. Closing a project writes a short summary and keeps the folder.

Phase 2

Time from a timer, from Claude chats and from activity suggestions, each one approved by the person. Reports by client, project, person and month.

Monday stays our live system for now. Projects copy Monday's shape, so moving across later is a straight swap: Monday projects become cards, subitems become to-dos, and booked hours come in marked "from Tracket".

Words

A few words explained

Card
The small file in a project's folder that holds its details, like a label on a box.
Key
A project's fixed address, such as skyseal/website-rebuild. To-dos and, later, time entries use it to point at the project.
Brain helper
A small script inside the brain that makes every change. The app asks it to make changes and never edits brain files itself.
Sync
How the brain shares changes with the team. If two people change the same line before syncing, it stops until someone sorts it out. The plan avoids that by never stamping "last edited" into files.
Stage
An optional label that groups a project's to-dos, such as Build or Launch.
