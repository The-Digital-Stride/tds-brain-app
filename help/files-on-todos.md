## What it does

A task can have files. They are listed under its details, in **Files**. You can add a file that is already in the library, or upload a new one. Uploads are saved in the library, so they also show in Images and Documents.

## Why it helps

- Everything for the job is in one place.
- Removing a file from a task never deletes it.

## How to use it

1. Open a task. Its files are under the details. Press a file's name to open it.
2. Press **Add a file**.
3. Choose **From the library**. Search for a name, tick one or more files, then press **Add file**.
4. Or choose **Upload** to pick files from your Mac. Only PNG, JPG, WebP, GIF, PDF, Word, Excel, PowerPoint, CSV, Markdown and text files can be added. Each can be up to 32 MB.
5. To add a web page, press **Add a link**. Paste the address and name it if you like.
6. To remove a file or a link from this task, press the cross beside it. A file stays in the library.
7. On a task you passed on, the files and links are listed too. You can open them but not change them.

## Good to know

- An upload goes into the task's client folder, in Files or Images. This works when the task's client is set and matches a client in the brain.
- Otherwise it goes to your personal files. Cortex says so first: the file saves to your personal files, and only you can open it.
- To add a personal file to a team task, Cortex asks first. Its name shows to everyone with the brain once it syncs, but only you can open it.
- A link must start with http or https.
- Adding or removing a file or a link is noted in the task's updates.
- If a file can't be found, the list says so.
- This needs the newest version of the brain's `todo` skill. Until then the buttons don't show.

## Try this

Open a task, press **Add a file**, choose **From the library** and search for a logo.
