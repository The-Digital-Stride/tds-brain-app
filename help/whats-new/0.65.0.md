title: Chats remember their project
pages: [projects, picking-the-client]
---

A chat started from **Working on**, from a project's to-do, or with **New chat for this project** now belongs to that project. Claude saves the work it makes in the project's folder. You find it under the project's **Files**.

The chat keeps its client and project when you open it again later.

If a client has open projects, Claude asks which one a new document or page is for before it saves it.
