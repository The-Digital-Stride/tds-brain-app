    New pieces (for the design-system doc)

    Everything else is an existing class or token.

    1. Side panel, .dock-panel hosting a settings list. Reuses the dock look (glass, radius 16, .panel-head, 332px, pushes Home), opened by the existing panel toggle (PanelToggle, icon only, top right of Home's sheet bar). New: it holds Home's own controls and keeps Home visible and live. Under 1100px it floats over Home with the veil, as This chat's dock does; the veil or Esc closes it. Docked, only Close does. No new sheet, no Confirm.
    2. Switch row list, .lib-list. The existing .setting row with a .switch (whole row is the label), hairlines between rows, a .hint under the title for conditional cards.
    3. Shortcut row, .home-shortcuts. A wrapping flex row (gap 8) of quiet small buttons that replaces the single .home-gm line.
    4. Panel shortcut item, .lib-shortcut. Name and kind (.line-title, .line-meta) on a --tint-04 row with a trailing X icon button (Actions rule 3).
    5. Section head with an action, .lib-sec-head. An h3 with the primary + at the right end (Actions rule 7).
    6. Grouped add list. The .popover with .menu-rows plus small iron group headings (Skills, Tools) as in the palette's .grp, and a .meta line ("Also in Pinned skills").
    7. Tray foot with a status line, .tray-hidden. "N cards hidden." (.hint) with a quiet small "Show hidden cards" (opens the panel) on the left; "Reset card order" stays at the right.
    8. Lone last card spans the tray, Home only. .home-tray[data-odd="true"] > .card:last-child { grid-column: 1 / -1 }, with data-odd set from the count of shown cards.
    9. Panel foot, "Show everything again". A quiet small button that clears hidden items at once (no Confirm), keeps shortcuts, and says "Every card is back on Home".
    10. Empty tray line. A centred .hint inside .tray: "Your Home has no cards. Customise Home to add some."
