## What it does

You can delete an image or a document from the library. Cortex doesn't erase it straight away. It keeps a copy for 30 days, so you can ask for it back.

## Why it helps

- The library stays tidy.
- A mistake is easy to fix: press Undo within a few seconds, or ask Claude later.
- Your team can see who deleted what, and when.

## How to use it

1. Open Images or Documents, and find the file.
2. Point at the file, or tab to it, and a bin button appears on its tile or row. It says "Delete file:" and then the file's name. You'll also find it when the file is open large.
3. A line appears with **Undo**. Press it within 10 seconds to keep the file. Do nothing, and the file is deleted.

Once it's deleted, Cortex says the file is kept for 30 days.

## Good to know

- Who can delete what: anyone on the team can delete a client's files. Only an owner can delete a template. Your personal files can't be deleted from Cortex.
- Getting a file back: after the Undo has gone, ask Claude to put it back. Try "Put back the logo I deleted yesterday." After 30 days it is gone for good.
- If there is no bin: some files are kept on this Mac only. Claude also relies on a few files, such as a client's profile, so Cortex won't let you delete them. If no file has a bin, the brain needs its latest update. Ask an owner.
- A deleted file also leaves any pinned list on Home.
- If someone else changed the file after you opened the library, Cortex stops and tells you. Have a look, then try again.

## Try this

Open a test image in Images, press its bin, then press **Undo** to see how it works.
