title: Updates on tasks, and handing them back
pages: [task-updates, files-on-todos, passing-todos-on]
---

- Say what you did on a task. Each task now has an **Updates** list with who did what, and when. See [Updates and handing back](help:task-updates).
- Hand a task back to the person who gave it to you, with a note, in one press.
- Reply on a task you passed on, without taking it back.
- Add web links to a task, next to its files. See [Files on tasks](help:files-on-todos).
- Add a note when you pass a task on. See [Passing a task on](help:passing-todos-on).
