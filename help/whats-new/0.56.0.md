title: Filter your to-dos by project
pages: [todos, projects]
---

The To-dos drawer has one **Project** filter for **Mine**, **Open** and **Asked**. Pick a project to see only its to-dos.

A to-do in a project shows the project's name on its row. Press it to filter the drawer to that project.

A new to-do you add while a project is picked starts in that project.
