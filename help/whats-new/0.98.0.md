title: See how Claude is used on this Mac
pages: [performance]
---

Owners and scouts have a new **Performance** tab in Settings. It shows how much Claude Code is used on this Mac, what that would cost at list prices, and where it goes. It also compares sessions with Code Mode on and off. It updates once a day, and you can press **Update now**. See [Performance](help:performance).
