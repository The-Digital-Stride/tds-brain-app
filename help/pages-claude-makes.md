## What it does

Claude can build a web page, such as a report or a chart. When Claude finishes a reply that made or changed a page, the page opens in Cortex.

## Why it helps

- You see the result straight away, in the app.
- You can ask for changes in plain words.
- Older versions are kept, so you can go back.

## How to use it

1. Ask Claude for a page, such as "Make a one-page summary of this report".
2. Wait for the reply to finish. The page opens by itself.
3. Type a note in the box under it. The box says **Suggest a change to this page**.
4. To go back to a page later, open **Pages** on the Files tab.

Buttons at the top of the page can include **Download with TDS branding**, **Open in Documents**, **Open on claude.ai** and **Copy link**.

## Good to know

- If there's more than one version, a **Version** list lets you pick one.
- While Claude is still writing, the page says "Claude is still working on this page."
- Some parts of a page only work on claude.ai. Cortex then says so.
- To keep a claude.ai page with a project, press **Add a claude.ai page** on the project's **Files** tab. See [Projects](help:projects).
- A page never opens over something you already have open.

## Try this

Ask "Make a page that compares our three most recent reports". Then suggest one change.
