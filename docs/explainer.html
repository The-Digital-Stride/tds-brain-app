TDS Brain App: a face for the brain, not a part of it

The app is one more way in, beside the terminal and the IDE. It stores none of the brain and the brain knows nothing about it. Use it, or carry on in the terminal as now. Both drive the same engine against the same folder.

1. Where the app sits

It keeps nothing of the brain'sNo copied skills, no client data. Its own notes (pins, layout) live in the app's folder, outside the brain, and never sync.
It asks the engine, never replaces itEvery chat is the real Claude Code started in the brain folder, so role gates, logging and rules apply exactly as in the terminal.
Claude Code onlyAn internal tool built for one engine. That keeps the brain's hooks, role gates and connectors working exactly as they do in the terminal.
Switch faces whenever you likeStart a job in the app, pick it up in the terminal. Sessions belong to Claude Code, not to the app.

2. What the face looks like

A sketch of the shell, not a design. Each numbered part is a small app in its own right, plugged into the shell. The table underneath says where each one gets its information.

3. What happens when the brain is updated

Nobody installs anything. The app notices the folder has changed and re-reads it.

  1. A skill changesA scout edits one, or a vendor update lands.
  2. Sync delivers itThe Agency Brain app brings it to every laptop, as it does today.
  3. The app re-readsIt watches the folder, so the skills list and to-dos refresh by themselves.
  4. Next chat uses itThe engine loads the new skill and rules. No app release.

If a skill is renamed or removed, any screen tuned for it simply goes unused and that skill falls back to plain chat. Nothing breaks.

4. The steps that need care

ApprovalsToday's Workbench buttons start Claude with permission checks switched off. The app should ask instead, in plain words, as in the sketch.
Only this laptop may talk to itThe app's local server can start Claude with file access, so no other web page may reach it. Needs a security review before the team uses it.
Direct writes sync to everyoneTicking a to-do edits a shared file, which reaches the team in about 90 seconds. Panels that write must follow the brain's own file rules.
Anthropic's usage rulesNobody signs in again: the app uses the Claude Code sign-in each person already has. The open point is permission, not technology. Anthropic's rules for apps built on Claude Code are unclear for a staff tool, so get their confirmation before rollout.

Terms

Agent SDK. Anthropic's official toolkit for driving Claude Code from your own program. It hands over each reply, question and permission request as data, which is why the app can show buttons and cards instead of terminal text.
Engine. Used here for Claude Code itself: the program that reads the brain's skills and rules and does the work, whichever face you used to ask.
Local file only. Nothing here is in the brain folder or published anywhere. Based on the feasibility study of 11 November 2026.
