## What it does

**Let the app change tasks** is a switch in Settings, on the **General** tab. When it is on, you can mark tasks as done, add, edit, pass them on and delete them in Cortex.

## Why it helps

- Everything about a task happens in one place.
- Each change is saved in the Brain, so the whole team sees the same list.
- It stays off until you choose, so nothing changes by accident.

## How to use it

1. Open Settings from the rail. It opens on the **General** tab.
2. Find **Preferences**.
3. Switch on **Let the app change tasks**.
4. Open the Tasks drawer. The add button is now there, and so is **Edit** in each task's panel. If they aren't, your role may not be allowed to use them yet. Ask whoever looks after Cortex.

![The Let the app change tasks switch in Settings.](images/settings-todos-switch.webp)

## Good to know

- It is off by default while Cortex is still being tested.
- With it off, you can still read your own tasks and the ones open to anyone. Press a title to read one in the panel.
- Switching it off again stops changes from Cortex. It doesn't undo changes already made.
- The setting belongs to this computer, not to your teammates.
- Personal tasks need this switch too.

## Try this

Switch it on, then add one small task for yourself.
