## What it does

A project code is a short code such as AST4K7. It is your client's code, then a digit, a letter and a digit. Cortex uses it to tell which project a meeting belongs to, and which project an email may belong to.

## Why it helps

- A meeting with the code in its invite title or description shows on the right project's Meetings card. Filing its notes is still a separate step.
- An email with the code in its subject or text is suggested for that project. It waits for the inbox owner's OK before it is saved.
- You can find any project by typing its code in the search.

## How to use it

1. Open a project. Its code is at the top of the **Overview**.
2. Press **Copy**. It copies the code in square brackets, like [AST4K7], so it stands out.
3. Paste it in the title or description of a meeting invite, or in an email's subject or text.
4. No code yet? Press **Make a code**. If the client has no client code, add one to its profile first.
5. On the Projects list, **Give projects codes** gives every project without one a code. Only an owner of the Brain sees it, and you only need it once.
6. If two projects share a code, neither shows Copy. Press **Make a new code** on the one that should change.

## Good to know

- Put a code in an email's subject or text, never in your signature. It would tag every email you send.
- A code only points to a project. It never lets anyone put anything into it. An email still needs the inbox owner's yes, shown under **Waiting for your OK**.
- Search on the Projects list and **Search or jump to** both find a project by its code. Capital letters and brackets don't matter.

## Try this

Open a project and press **Copy**.
