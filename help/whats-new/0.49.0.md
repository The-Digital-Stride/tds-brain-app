title: Ad Manager chats open beside the board
pages: [ad-manager]
---

When you press **Run** or **Open chat** in **Ad Manager**, the chat now opens on the right, and the board stays in view behind it. You can keep reading the board while Claude works.

**Hide chat** (or Esc) tucks the chat away while it carries on, and you'll still find it in Chats. Esc leaves it open while you're halfway through a message. **Open full screen** moves it to the chat screen, with anything you've typed. Drag the chat's left edge to make it wider or narrower. In a narrow window the chat covers the board; hide it to see the board again.
